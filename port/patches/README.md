# port/patches

Generated by `tools/r3_survey.py <EBOOT.elf> --write-insn port/patches` from
the player's own decrypted EBOOT, for the version it is (01.00 or 01.05):

- `eboot_<version>.insn.json` — the code words of RPCS3's "Unlock FPS" patch,
  which `tools/rebuild.sh lift` passes to `ppu_lifter.py --insn-patches`
  (lifted in both forms, picked at run time by `g_res_unlock_fps`).
- `eboot_<version>.words.h` — the original value of every word the patches
  touch (the signature `port/patches.cpp` checks first) and the data words it
  writes for `RES_UNLOCK_FPS=1` and `RES_FOV=<f>`.

An `eboot_<version>.sjlj.json` here is passed to `ppu_lifter.py --sjlj` (a
title's setjmp/longjmp, as the Resistance: Fall of Man port needed for Lua).
